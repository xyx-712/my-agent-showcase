## 公网部署防护现状

- 已实现：单文件 5 MiB、每文件解析 60000 字符；每身份最多 12 个独立文件、总解析文字 180000 字符。文件解析和压缩展开另有有界限制。
- 未实现完整入口保护：5 MiB 检查在 multipart 解析后，不能替代反向代理/网关对整个请求体和上传时间的限制。
- 认证相关调用有每进程 300 秒窗口/8 次失败限速，但不是跨 Worker 共享限流；聊天、上传及访客创建没有统一流量限制。
- 没有全局磁盘配额、访客身份总量限制和磁盘不足的统一策略；每身份额度不能防止无限创建身份消耗存储。
- 公网使用必须落实 HTTPS、准确 Origin、可信代理配置和以上入口/存储防护；Local 单 Worker 验收不等于公网安全验收。共享 Chroma 端口不应直接暴露公网。

## 最小后续方案

发布源码无需恢复旧 Git 历史。公开服务部署前，先配置入口体积/速率/超时和全局存储预算，再进行针对性限流、越权和浏览器验收；本轮没有修改任何核心业务功能或新增公网入口。提交邮箱、远程地址、版本标签需另行确认。
